YOUNGJI INTERNATIONAL SCHOOL — COMPLETE FRONTEND PACKAGE

Included:
- index.html
- styles.css
- app.js
- assets/school-logo.png
- assets/dean-daniel-jara.jpg
- assets/school-background.jpg

Features implemented in JavaScript/localStorage:
1. Homepage with the supplied school background photo.
2. School logo and Dean Daniel Jara photo.
3. Teachers Portal button between Home and Admin.
4. Shared Teachers Portal login.
5. Admin login.
6. Student evaluation without a student account.
7. Evaluation form fields: Name, Section, Email, Teacher, ratings, Comment.
8. Teacher profiles with rating summaries.
9. Admin can view student information and comments.
10. Admin-only Delete button for individual evaluations/comments.
11. Data persists in the browser using localStorage.

IMPORTANT:
This is a browser-only prototype. The credentials and evaluation data are stored in JavaScript/localStorage, so this is NOT secure for a real production school system. For a real deployment, use a server-side backend (for example PHP/MySQL, Node.js, or another authenticated API) and enforce admin permissions on the server.
